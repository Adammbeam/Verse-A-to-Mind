Username finder

Type a name people use in public. Verse asks a short fixed list of major sites whether a profile page for that name is there, then marks each one found, not found, or could not be checked.

    The list does not change with what you type, and Verse does not follow an address you supply. The name is sent once so those public pages can be asked, and it is not kept. A page that answers is not proof of who holds the name. A site that blocks the check, or uses a different shape of name, stays at could not be checked, with its link so you can look.
