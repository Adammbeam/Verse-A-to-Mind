Site safety check

Type a domain you run. Verse reads the public signals that site already publishes: whether HTTPS answers and plain HTTP sends people there, whether the connection is encrypted, the safety headers and cookie flags on the homepage, the security.txt contact file, and the SPF and DMARC mail records. Each row says what that signal means and how to fix it when it is missing.

Verse does not scan ports or sign in, and it does not keep who asked. A result may be reused for a few minutes so the same site is not fetched again. It will not open an IP address, a private network, or a port other than the normal web ports.
