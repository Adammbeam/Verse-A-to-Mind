- **Site safety check (`/security/check/`, `void-live-deploy/lib/security-check.js`, `void-live-deploy/functions/api/security-check.js`, `tools/security-check.test.mjs`):** a visitor types a public domain and Verse reads the homepage's HTTPS, TLS, safety headers, cookie flags, security.txt, and the SPF and DMARC records through a public DNS-over-HTTPS resolver. IP addresses, private networks and non-standard ports are refused before anything is opened. The domain is not stored.
