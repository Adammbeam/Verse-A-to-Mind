Prompt-to-working-thing rate (`tools/pwtsr.mjs`, cases `tools/pwtsr-cases.json`, test `tools/pwtsr.test.mjs`): one score for asks that produce a usable card of the right skill. Routing reuses the skill order (the same first match as `tools/skills-check.mjs`). `--browser` opens the local page in headless Chrome, stubs `/api/answer`, and blocks every other host, so an ask never reaches Workers AI or Groq. A low score is a report, exit 0. Misses are job cards in that report. Levels 2, 3, 5, 6, 7, 9 and 10 are not in the case file yet.
