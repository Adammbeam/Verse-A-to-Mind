Ability floors (`tools/ability-floors.mjs`, `void-live-deploy/lib/ability-floors.js`, `void-live-deploy/tower.abilities.json`, test `tools/ability-floors.test.mjs`): the Versus card and elevator work from plain-word jobs taken from the capability inventory. A floor is missing when that inventory shows no working tool, part when a tool does only some of the job, and has when a tool does it. Old site floor ids stay as aliases, and the old side-by-side addresses still open. The file is owner-only with the other `tower.*` files. Visitors still get the Out of Order sign.
