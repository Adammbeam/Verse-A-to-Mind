# On-device answers, opt-in

What starts it: an ask for answers that stay on the visitor's device, or a change to the opt-in control, the CSP, or the local answer card.

1. The control is a button beside the ask box (`[data-local-toggle]` in `void.html`). It starts off, is remembered in `a2m.void.local.v1`, and loads the model only when clicked. No model is fetched on page load.
2. Keep the default path intact: `showAnswer()` tries the local branch only when the toggle is on, the ask is short, and no page or summary heading came with it. Any failure turns the toggle off and sends the ask to `/api/answer`.
3. The library is imported from a public CDN at click time. Its origins must be allowed in `script-src` for the front page (`void-live-deploy/_headers` and the `REST` header in `tools/csp-hashes.mjs`); the pages with their own narrower rules keep them. The library and license must appear in `domains/autosalvage.outside.json`, `domains/autosalvage.unified.json`, and the generated `/credits/`.
4. Prove the page offline and live: `node --test tools/local-model.test.mjs` checks the three page copies, the order of the two branches, the narrow CSP, and the credit. `node tools/local-model-live.mjs` drives the real origin in Edge with WebGPU; before the change ships it serves the worktree page with its own CSP, and `node tools/local-model-live.mjs --shipped` checks the deployed page afterwards. The live run must show the default ask reaching `/api/answer`, the opted-in ask writing a short answer on the device with no call, and the toggle switching back to the server route.
5. Mistakes: a model import left at the top level breaks the merge gate, where there is no `node_modules` — keep it behind a click-time dynamic import. A CSP opened on every page is wider than the change needs. Asks like "what is 2+2?" are taken by a local skill before the answer engine; use "why is the sky blue?" to reach the answer route in a live probe. A repeated ask does not answer again — it fills the card it already has — so a browser probe uses three different wordings for the online, local and back-online asks.
